## 使用约定

- 这些记录不替代真实测试与发布校验；发布门禁、平台实测范围与“未验证”清单以最新记录
  与 `docs/deployment/` 的交付状态为准。
- 记录中的数字、路径、Git 提交与产物摘要都是**当时时点**的事实；后续步骤可能已改变代码
  与产物，引用时请同时注明记录日期。
- 过程性开发/审计报告保存在本机 `.ai/lead/reports/`（AI 专用，不随发布包），可在内部
  追溯时按记录中给出的名称查找；对外交付只使用本目录与 `docs/` 下的正式文档。
