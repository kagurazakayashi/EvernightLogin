## 6. 缺口、边界与未测项（不阻塞本步结论，但不得冒充已验收）

1. **真实跨进程竞争**（NOT_TESTED）：并发唯一性在进程内多协程/多服务实例验证；真实独立进程
   同时消费同一凭证/任务的唯一性未构造（会涉及多进程 SQLite 协调，本步未做）。
2. **真实 OS 强杀后恢复**（PARTIAL/NOT_TESTED）：现有证据为“合成残留 + 遗留锁”回收与子进程
   context 清理；未在真实备份写入中途强杀进程并验证明文残留窗口与恢复。步骤 80 已记录强杀后
   至下次 Create 前存在明文暂存窗口（可识别残留锁立即清），本步未改变该边界。
3. **真实 ENOSPC**（NOT_TESTED）：以受控容量上限与有界 writer 模拟；未真实写满磁盘（避免消耗
   真实磁盘且不可控）。真实驱动 ENOSPC 映射为 `BACKUP_FAILED` 的代码路径已有实现与错误分类测试，
   但未做真实磁盘满注入。
4. **`-race`**（NOT_TESTED）：本步按约束串行、`GOMAXPROCS=2`，未用 race detector；竞争保证由
   唯一性断言与 `-count=3` 复核支撑，不等于 race 检测通过。
5. **部署后独立服务 / 跨机器恢复**（NOT_TESTED）：`cmd/login-server` 仍无 HTTP 服务装配（步骤
   92/93 已记录），恢复演练为进程内真实实现 + 隔离副本；未在部署后服务上执行备份→恢复。
6. 非 Windows/SQLite 平台与 MySQL/PostgreSQL/SQL Server 的真实恢复未测（既定约束：只运行
   Windows/SQLite，其他方言仅静态/编译）。
