# 安全审计与统计报告

本文说明 login 记录哪些安全审计、怎么查、保留多久，以及统计看板与报告（HTML/PDF/CSV/
JSON/Markdown）能做什么、缺什么。审计与报告是**两个独立系统**：审计是安全事实记录，
报告是从统计快照生成的数据产物，报告不能替代审计。

## 1. 安全审计模型

每条审计事件至少包含：发生时间、操作者（用户/系统/本地管理员标识）、目标（用户、应用、
资源）、动作、结果（成功/失败/拒绝/取消）、公开错误码、request_id，后台任务另有
task_id；精确内部原因码（reason_code）只保存在受限审计中，不对外返回。

关键不变量：

- **审计与关键管理变更一致**：关键操作（权限变更、恢复、备份等）与审计写入一致；审计
  不可用时**拒绝**关键管理变更，不留下“操作成功但没有记录”的假象。
- **不可静默改写**：原始审计记录不可通过普通业务操作修改/删除；清理只能按保留策略由
  root 受控执行，并记录清理本身的审计。
- **取消语义分开**：取消请求、取消被拒绝、实际取消、超时、失败分别记录；取消请求不等于
  实际取消。
- **不泄露秘密**：审计/报告不记录密码、Token、验证码、MFA 秘密、二维码领取绑定、私钥。
- 权限拒绝通常表示保护正常生效；集中异常拒绝、跨应用尝试、刷新令牌重放值得进一步调查，
  但不能仅凭一条事件断言用户恶意。

## 2. 谁可以查、查什么

| 能力 | 所需权限 | 说明 |
|---|---|---|
| 查看审计记录 | `audit.read` | 按获准数据范围（系统级或应用级）过滤，范围进查询条件，不先全量读再过滤 |
| 导出审计 | `audit.export` | 独立权限 + 敏感操作再次认证；异步任务生成，字段白名单 |
| 清理审计 | `audit.purge` | **仅 root** + 敏感操作策略；先只读预估再提交确认，分批删除 |
| 查看本人活动 | 本人登录即可 | 仅本人安全活动，不提供他人或系统范围 |

查询筛选（受控字段）：时间区间（左闭右开）、应用/系统范围、操作者类型/ID、动作、结果、
公开错误码、request_id/task_id、目标类型/ID；排序只允许按时间（正序/倒序，事件 ID 决胜）。
分页不伪造总数，只给 `HasMore`。

- 默认保留期 **180 天**（未设置时使用内置默认值）；root 可设置 **1～3650 天**，带版本
  检查（并发修改冲突 `CONFLICT`）。
- 早于保留期的详情返回“已过期”而不是“不存在”，两者区分。
- 第一版**没有自动定时清理**：清理保留策略与 root 手动清理已实现，自动调度属未实现项。
- 导出产物：受控目录 + 随机文件名 + `O_EXCL` 创建、行数/字节上限、CSV 防公式注入、
  记录 SHA-256 与大小；下载前再次授权并复核产物名称/类型/大小/过期，权限或范围收缩后
  不可下载。
- 受保护追加日志由数据库触发器禁止 UPDATE/DELETE；清理不会抹掉本次清理自身的审计。

## 3. 统计与报告

### 3.1 统计口径（避免“看起来不一致”）

- 时间窗口左闭右开 `[Start, End)`，IANA 时区白名单，自然日/周（周一起始）/月分桶；
  跨午夜/周/月与夏令时不重复、不漏计；结束晚于注入时钟时裁剪并标记，未完成桶标记。
- **活跃用户**只统计完整成功认证（服务端会话签发）并按稳定用户 ID 跨应用去重；受限会话
  与等待第二因素不计入。
- **错误统计**按错误码/类别/严重度/应用聚合；原始次数与按 request_id/task_id 去重的失败
  请求/任务数分开；等待授权、正常拒绝、主动取消、数据质量警告与故障分开。
- 缺失/未知/未采样/保留期不足显示“—/未知/不完整”，**不补零**；真实零值显示 0。
- 对比期增幅：零基数显示“新增”，前值>0 给百分比；不完整标 unavailable。

### 3.2 报告格式与产物

| 格式 | 状态与要求 |
|---|---|
| HTML | 已实现：自包含、无外部在线脚本/字体；中文与特殊字符转义 |
| CSV | 已实现：逐列语义 + 防公式注入（`= + - @` 等前缀加单引号）；数值列保持数字 |
| JSON | 已实现：纯数据编码，RFC3339 时间；零值时间输出 null |
| Markdown | 已实现（可选格式之一）；给智能体阅读，含明确“内容不可信”边界 |
| PDF | 已实现生成路径，但**中文字体需要宿主提供**：仓库不随包附带 PDF 字体，未做真实 PDF 渲染实测；缺少字体时 PDF 输出会失败并明确报错，不会静默降级 |

报告语义：

- 只含聚合统计与受控字段，不导出原始审计全量记录/内部原因码/凭证/秘密。
- 数据不足时输出 `completeness` 与中文说明，`unknown`/`partial`/`in_progress`/
  `not_enabled` 显式标注，缺失不当 0。
- 生成、查看、下载、导出、计划管理分别授权；权限撤销后不因“曾拥有”永久可下载。
- 定期报告任务每次执行重新检查所有者/执行身份权限；报告失败不污染原始审计。
- 取消/超时/失败/成功分别记录真实执行者与终态。

### 3.3 页面

内置页面覆盖：审计与错误诊断、错误码检索、导出任务、root 审计清理、统计看板（摘要 +
错误类别分布 + 系统状态快照）、活跃度与错误趋势、错误分类明细、报告计划/历史/下载/
保留清理、备份计划/任务。页面通过 `ui.v1` 命名路由与视图模型使用，不直接解析 DOM。

排障建议：先看 [troubleshooting.md](troubleshooting.md) 的错误码表；涉及“统计与审计数字
