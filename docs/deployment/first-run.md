# 首次配置（受限初始化）

本文说明 login 全新部署的首次配置流程、当前可用状态与防锁死要求。

## 1. 安全模型（不可变约束）

- 唯一 root：用户名固定为保留值 `root`，普通账户规则永久禁止该名称；数据库唯一索引
  保证至多一个 root。
- 无默认密码：全新数据库没有默认密码、默认口令或硬编码凭据，也没有“演示管理员”。
- 受限初始化：root 创建后处于 `pending_setup`（受限待配置）状态。它只有在本机完成
  一次性配置凭证兑换并继续配置强认证后，才可能进入 `ready`；在此之前不会签发可远程
  管理整个系统的正常高权限会话。
- 一次性、限时、本机：初始化凭证只出现一次，服务端只保存摘要；过期、被消费、被替换
  或用途/目标不匹配时统一拒绝（不区分具体原因，避免探测）。
- 没有远程匿名初始化接口：root 只能由本地受控流程创建，请求不能提交 `is_root`、
  `status`、`security_version` 或密码字段。

## 2. 当前可用状态（务必先读）

| 入口 | 状态 |
|---|---|
| 领域服务 `internal/bootstrap`（`Initialize`、`RedeemSetupCredential`、`ReissueSetupCredential`、`Status`、`AuthorizeStrongSetup`） | 已实现并有定向测试 |
| 独立服务/CLI 的首次配置入口 | **未实现**；`cmd/login-server` 只提供 `--version`/`--help` |
| HTTP 首次配置页面或接口 | **未实现**（没有匿名远程入口） |
| 已初始化的 root 恢复通道 | `cmd/loginctl root-recover`：本地应急恢复密码/MFA，要求服务停止或维护状态并取得排他锁 |

结论：**当前版本无法由外部部署者完成首次配置**。`internal/bootstrap` 是模块内部包，
外部宿主无法导入。独立部署要等“服务启动装配 + 首次配置入口”实现后才能按第 3 节流程
操作；在此之前不要创建生产 root，也不要把未初始化的服务暴露到网络。

## 3. 目标流程（装配完成后应满足的契约）

1. **准备主机与数据目录**：创建 `data/`（数据库）、`secrets/`（主密钥等）、`config/`、
   `backups/`、`logs/` 目录，限制为服务账号可读写，其他账号不可访问。
2. **写入配置**：从 `samples/login.server.example.yaml` 复制，替换占位符；秘密只通过
   `env:` 或 `file:` 引用，不写进 YAML。
3. **校验配置**：用配置加载器校验（当前可用 `go run ./examples/config-load -config <path>`；
   不要跳过，也不要为了跑起来删掉安全校验）。
4. **执行迁移**：在维护窗口内对空数据库按版本顺序执行迁移；迁移前先确认备份可用。
5. **本地初始化**：由本机受控进程调用初始化服务创建 root，获得**一次性配置凭证**；
   凭证只输出一次，不写日志、不写文件、不通过聊天工具传递。
6. **兑换并配置强认证**：用一次性凭证兑换受限配置授权，设置正式密码并完成强认证
   配置（MFA/Passkey 等，按已实现能力）；敏感配置操作按需再次验证。
7. **进入 ready 后开放访问**：确认健康/就绪检查通过、反向代理与 TLS 正确后再对外
   开放；默认只监听回环地址。
8. **记录与备份**：记录部署时间、版本、迁移版本、证书到期时间；建立加密热备份与
   恢复演练计划（见 `packaging.md` 与备份工具说明）。

## 4. 防锁死检查清单

- [ ] 已准备 `cmd/loginctl root-recover` 的本地执行条件（停服/维护 + 排他锁）。
- [ ] 主密钥与备份加密材料**分开保存**，并记录丢失后果（丢失即无法恢复备份）。
- [ ] root 的强认证方式至少保留两种可用路径（例如 Passkey + 恢复代码），不要只留一种。
- [ ] 恢复代码离线保存，已使用/过期的恢复代码及时重新生成。
- [ ] 初始化凭证未写入日志、工单、聊天记录或截屏；兑换完成后确认其已失效。
- [ ] 数据库文件、秘密文件的服务账号权限与其他账号隔离；不要把 `database/`、`secrets/`
     放进 Web 根目录或备份同步目录。
- [ ] 对外暴露前确认：只监听回环或已配置 TLS/受信代理；未初始化服务不暴露公网。

## 5. 已知限制

- 初始化入口未装配（见第 2 节），本文第 3 节是装配完成后必须满足的契约，不是当前可执行
  步骤。
- 首次配置的邮件/通知、多审批、root 强认证生产适配器按其他步骤实现；当前不能把示例
  替身当作生产鉴权。
- 迁移、诊断、备份命令均为本地工具，不提供远程执行；不要把本地工具包装成网络接口。
