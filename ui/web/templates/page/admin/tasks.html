取消语义（任务与邮件投递不同）

  • 取消任务：使用 loginctl task cancel 或任务 API 提交取消请求，仅表示“请求已受理”；最终是否取消以 cancel_requested → cancelled/failed 等真实终态为准，处理器可能仍在收尾。
  • 取消邮件投递：终止某封邮件在可靠投递队列中的发送（投递记录状态转为 cancelled），它不是取消产生该邮件的后台任务，也不会回滚已完成的业务操作或已发送邮件。

本页为只读视图：不提供在此直接取消任务的按钮，避免把“已请求”误显示为“已取消”。
